# OneCode TUI 手测清单（首次发布前）

本清单覆盖 OneCode Terminal.Gui v2 TUI 的**交互**与**功能**两个维度，供首次发布前人工逐项核过。
自动化测试无法覆盖真实终端的渲染、按键时序与体感，本清单是对 `dotnet test` 的补充而非替代。

## 使用方法

- 逐项执行，在「结果」列标记 `☐ 通过` / `☐ 失败`（失败须在缺陷记录表登记编号）。
- 标 **[P]** 的条目需要真实模型 provider（API Key），其余条目只需本地二进制与测试仓库。
- 行为规格的权威来源：[斜杠命令参考](commands.md)、[快捷键参考](keybindings.md)、[配置项参考](settings.md)、[TUI 设计系统](../src/OneCode.App/Tui/DESIGN.md)、[团队模式](team-modes.md)。本清单条目与规范不一致时，以规范文档与代码为准，并同步修订本清单。
- 建议按分区推进：0 → 17；第 13 区（命令）可在任意 provider 就绪后单独走查。
- 多终端与环境档位不必全量复测：以终端 A（Windows Terminal）为基准走完全部条目，终端 B/C 与各宽度档位只需抽查第 5 / 6 / 11 / 12 区。
